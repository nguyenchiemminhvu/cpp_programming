# C++11 › Lambda Expressions

## Overview
Lambdas provide anonymous, inline callable objects. They are syntactic sugar over
a locally defined functor class, and integrate naturally with the STL algorithms.

## Syntax
```
[capture-list](params) mutable -> return_type { body }
```

## Capture Modes

| Syntax | Meaning |
|--------|---------|
| `[]`   | Capture nothing |
| `[=]`  | Capture all locals by value |
| `[&]`  | Capture all locals by reference |
| `[x]`  | Capture `x` by value |
| `[&x]` | Capture `x` by reference |
| `[=, &x]` | Defaults to value; `x` by reference |
| `[this]` | Capture enclosing object's `this` pointer |

## Key Concepts
- A lambda is a **closure type** — a unique, unnamed class generated by the compiler.
- The operator `()` of the generated class is `const` by default; use `mutable` to allow modifying captured copies.
- `std::function<R(Args...)>` can store any callable including lambdas (with type-erasure overhead).
- Prefer storing lambdas in `auto` variables rather than `std::function` when the type is local.
